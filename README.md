### ESG-RAG — Document intelligence for sustainable finance

A Python-based prototype for exploring ESG and sustainable-finance documents through retrieval-augmented generation. It brings document ingestion, retrieval, and language-model responses into one application workflow.

**What the current prototype demonstrates**

- Ingestion of digital and scanned PDF documents.
- OCR processing for scanned content using Tesseract.
- Semantic retrieval with ChromaDB.
- Keyword retrieval with BM25 and result fusion using Reciprocal Rank Fusion (RRF).
- Integration with locally hosted language models through Ollama.
- ESG-related entity and key numerical-information checks.
- A Streamlit interface for interacting with the document collection.
- SQLite-based logging of application interactions and feedback.

**Technology:** Python, Streamlit, Ollama, ChromaDB, BM25, Reciprocal Rank Fusion, Tesseract OCR, SQLite.

[Explore the ESG-RAG repository](https://github.com/MobeenShahroz/esg-rag-chatbot)

> **Project status:** This is a public prototype and should not be treated as production-ready or used with confidential/client documents in its current form. Authentication, secret handling, document-storage controls, repository synchronization, and deployment safeguards require further hardening before sensitive-data or production use. The project repository will be updated separately.

## How I approach a project

1. **Understand the use case**: clarify the problem, intended users, inputs, expected outputs, and constraints.
2. **Assess the data**: review representative samples, data quality, labels, class balance, and privacy considerations.
3. **Set a baseline**: choose appropriate metrics and establish a measurable starting point.
4. **Develop and evaluate**: implement the agreed method, compare alternatives, and examine errors and limitations.
5. **Integrate and hand over**: provide the agreed application/API components, source code, evaluation results, and documentation.

Scope, milestones, data requirements, and deliverables are agreed before development begins.
